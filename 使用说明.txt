自动校时（Win7/8/10/11 通用）— 使用说明
========================================

一、这是什么
  双击就能把电脑时间对准标准时间的绿色小工具。走的是国家授时中心/阿里云/腾讯云的
  NTP 服务，误差一般不到 1 秒。单文件，不用安装，不装任何额外组件。

二、怎么用（三步）
  1. 把「自动校时.exe」拷到电脑任意位置，例如 D:\工具\自动校时.exe
     （建议别放 C:\Program Files，那样日志写不进去）
  2. 双击它。会弹一次"用户账户控制"提示，点【是】
  3. 窗口里点【立即同步】。几秒后状态栏显示"已校准完成"或"时间已准确"

三、界面上都有什么
  当前时间     实时显示本机时间
  状态         显示用了哪台服务器、偏差多少秒、网络往返多少毫秒
  时间服务器   下拉框选择。内置 6 个国内源：
                  ntp.aliyun.com（阿里云）
                  time1.cloud.tencent.com（腾讯云）
                  ntp.ntsc.ac.cn（国家授时中心）
                  cn.pool.ntp.org（国内 NTP 池）
                  time.windows.com（微软，国内常不通）
                  120.25.115.20（阿里云 IP 直连）
               想用内网服务器？在框里输入 IP 或域名，点「添加」，就加进列表了。
               「删除」只删自己添加的，内置的删不掉。
               同步时以你选中的那台为优先，它不通会自动按列表往下试，
               这时状态栏会写明"选中的 X 连不上，已自动改用 Y"，不会闷着换源。
               如果不想让它自动换，就勾上「只用所选服务器」——连不上直接报错，
               内网环境（只能用指定 NTP）建议勾这个。
  立即同步     手动校时，就是按这个按钮
  开机后自动同步   勾上 = 每次开机后 1 分钟自动校一次，以后不用手动点
  定时自动同步     勾上 = 按设定间隔（1/2/3/6/12/24 小时）自动校
  关闭         退出程序。勾选的自动同步会一直留在系统里

  勾选/取消这两个开关是即时生效的，会往系统里写入或删除计划任务。
  两个开关都勾上 = 开机自动校 + 定时自动校，最省心。

四、为什么双击会弹"用户账户控制"
  改系统时间必须管理员权限，程序里已经声明了，所以双击会自动申请提权，
  点"是"就行。这是正常现象，不是病毒。

五、常见问题
  · 提示"所有时间服务器均不可达"
    网络不通，或者防火墙/杀毒软件拦了 UDP 123 出站端口。
    内网机器的话，把"时间服务器"那一栏换成你们单位的内网 NTP 服务器 IP。

  · 提示"没有管理员权限"
    说明没点那个"是"。重新双击一次，UAC 必须点是。

  · 时间差不到 1 秒时显示"无需调整"
    故意的，避免每次都去写主板时钟，对硬件更友好。

  · 公司域环境的电脑改不了时间
    组策略可能收回了"更改系统时间"权限，这种情况任何工具都改不了，找网管。

  · 杀毒软件报毒（360 报"木马"、Defender 报"威胁"）
    这是误报，原因是这个程序干的三件事恰好和木马的行为特征重合：
      ① 要求管理员权限    ② 修改系统时间    ③ 写入开机自启的计划任务
    再加上它没有数字签名，360 的启发式引擎（QVM）就判成木马了。程序本身不发包回传、
    不联网下载、不改浏览器主页、不驻留内存，全部源码就在旁边，可以自己核对。

    360 的处理办法（推荐，一次就好）：
      a. 报毒弹窗里点【恢复并添加信任】/【信任此文件】，别点"立即处理"
      b. 如果已经被隔离了：打开 360 → 木马查杀 → 【隔离区】→ 找到 自动校时.exe
         → 勾选 → 【恢复】→ 弹出提示时选【添加信任】
      c. 主动加白：360 → 木马查杀 → 右上角【设置/信任区】→ 添加目录
         → 选 exe 所在的文件夹
      d. 还不行就临时退出 360 再双击运行，用完再打开

    Windows Defender 的处理办法：
      设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护
      → "管理设置" → 排除项 → 添加排除项 → 选文件和文件夹

    要彻底不报，只有两条路：给程序买代码签名证书，或者向杀软厂商提交误报申诉
    （见同目录的 360误报申诉.txt，能直接拿去申诉）。

六、运行日志
  程序目录下的 TimeSync.log，记录每次校时的时间、服务器、偏差。
  最多保留最近 200 行，删掉也不影响使用。

七、卸载
  在界面上把两个勾去掉，然后删掉 exe 就行，不留任何残留。

八、技术说明
  · 标准 SNTP 协议，UDP 123 端口
  · 偏差算法用 t1/t2/t3/t4 四个时间戳：偏移 = ((t2-t1)+(t3-t4))/2，
    已经算掉网络往返延迟，不是简单的"拿服务器时间盖本机"
  · 系统时间通过 SetSystemTime 写入，需要 SeSystemtimePrivilege 权限
  · 支持 Win7 SP1 及以上（Win7 自带 .NET Framework 3.5，无需另装）
  · 32 位程序，32/64 位系统都能跑
